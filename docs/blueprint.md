# **App Name**: Content Singh

## Core Features:

- AI Content Generation: Generate content based on user prompts using a large language model. The LLM will use a tool to decide when or if to incorporate information in its output.
- Content Display: Display the generated content in a clean, readable format.
- User Input and Output: Allow users to input prompts and receive generated content.

## Style Guidelines:

- Primary color: Neutral gray (#F5F5F5) for a professional feel.
- Secondary color: Dark gray (#333333) for text and important elements.
- Accent: Teal (#008080) for interactive elements and highlights.
- Clean and modern font for readability.
- Simple and consistent icons for key actions.
- Clear and intuitive layout for easy navigation.
- Subtle animations for loading and transitions.
